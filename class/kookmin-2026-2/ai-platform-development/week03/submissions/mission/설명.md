# 설명 — 동아리 행사 신청 집계 실습 기록

이 문서는 `event-attendance-check` 스킬로 사진동아리 가을 교류회 참가 신청을
집계하고, 신청 명단 변경을 반영·검증한 과정을 정리한 것이다.

## 1. 사용한 자료

| 구분 | 경로 | 수정 여부 |
| --- | --- | --- |
| 행사 안내문 | `week03/mission/행사안내.md` | 읽기만 (미수정) |
| 원본 신청 CSV | `week03/mission/참가신청.csv` | 읽기만 (미수정) |
| 변경본 CSV | `submissions/mission/참가신청_변경.csv` | 복사 후 A06만 변경 |
| 집계 코드 | `event-attendance-check/scripts/count_attendance.py` | — |
| 변경 검증 코드 | `event-attendance-check/scripts/verify_change.py` | — |

## 2. 역할 분담

- **Python**: CSV를 읽어 참가/불참, 간식별 수량, '받지 않음', 미응답(빈칸),
  생수(참가 인원수), 중복/오류를 집계하고 결과를 JSON으로 출력한다.
- **AI**: 안내문의 운영 기준(일정·정원·간식·준비물)을 파악하고, Python
  집계 JSON을 근거로 보고서와 준비 사항을 정리한다. 수치는 추측·보정하지 않는다.

## 3. 집계 기준 (행사안내.md 기반)

1. 참가 여부가 '참가'인 사람만 참가 인원에 포함.
2. '불참'은 참가 인원·간식 수량에서 제외.
3. 간식 '받지 않음'은 주문하지 않음.
4. 간식 선택 빈칸은 '미응답'으로 따로 집계(메뉴 임의 지정 금지).
5. 간식은 명시적으로 선택한 참가자만 1인 1개.
6. 생수는 간식 선택과 무관하게 참가 인원수만큼.
7. 중복 신청번호·필수 컬럼 누락·예상치 못한 값은 경고/오류로 보고.
8. 참가 인원과 정원(12명)을 비교해 초과 여부 확인.
9. 모든 수량은 Python 실행 결과 기준.

## 4. 실행 명령

```bash
cd event-attendance-check

# 처음(원본) 집계
python scripts/count_attendance.py "week03/mission/참가신청.csv" --capacity 12

# 변경본 집계
python scripts/count_attendance.py "submissions/mission/참가신청_변경.csv" --capacity 12

# 원본 vs 변경본 셀 단위 검증
python scripts/verify_change.py "week03/mission/참가신청.csv" "submissions/mission/참가신청_변경.csv"
```

## 5. 처음 집계 결과 (원본 CSV)

| 항목 | 값 |
| --- | --- |
| 전체 기록 | 12건 |
| 참가 / 불참 | 10명 / 2명 |
| 샌드위치 / 주먹밥 | 4개 / 4개 |
| 받지 않음 | 1명 |
| 미응답 | 1명 (A07) |
| 생수 | 10개 |
| 정원 확인 | 12명 중 10명, 여유 2, 초과 없음 |

→ `submissions/mission/처음보고서.md` 저장.

## 6. 신청 명단 변경

- 원본은 보존하고 `submissions/mission/참가신청_변경.csv`로 복사.
- 변경: **A06(윤민재)** 참가 여부 `불참` → `참가` (단 1개 셀).
- A06 간식 선택 `샌드위치` 및 나머지 모든 셀 유지.
- 변경 전 조건 확인: A06이 정확히 1건, 원래 값 `불참` → 조건 충족.

### 변경 검증 (verify_change.py)

- 행 수 동일(12/12), 컬럼 동일, 신청번호 집합 동일(A01~A12), 중복 없음.
- 변경된 셀: **A06 / 참가 여부: 불참 → 참가 단 1곳**.
- 허용 외 변경 셀: 없음.
- '받지 않음'(A04)과 빈칸 미응답(A07, A10)은 구분 유지, 임의로 채우지 않음.

기대값과 실제 결과가 완전히 일치하여 임의 보정 없이 그대로 사용했다.
보고서 저장 후 파일을 다시 읽어 Python 집계 JSON과 수치가 일치함을 확인했다.

## 9. 남은 확인 사항

- **A07(한수빈) 간식 미응답**: 9월 25일(금) 오후 5시까지 메뉴를 확인한 뒤
  주문 수량을 확정한다. 메뉴를 임의로 정하지 않는다.
- 변경 후 참가 11명으로 정원(12명)에 여유 1명뿐 → 추가 변경 시 정원 재확인.
- 간식 '주문 확정'과 '실제 주문 완료'는 구분한다.
