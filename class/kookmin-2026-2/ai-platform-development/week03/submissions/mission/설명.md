# 설명 — 동아리 행사 신청 집계 실습

- **에이전트**: 동아리 행사 준비 에이전트 (Kiro Crew)
- **스킬**: `event-attendance-check` — 참가 신청 CSV를 Python으로 집계하고 안내문 기준으로 준비 사항을 보고서로 정리.

## 만든 기준
- 수치는 Python 실행 결과(JSON)만 사용, 추측·보정 없음.
- 참가자만 집계, '불참' 제외.
- '받지 않음'과 빈칸(미응답)을 구분, 미응답은 임의로 채우지 않음.
- 생수 = 참가 인원수. 중복·누락·예상 밖 값은 경고/오류로 보고.
- 원본 파일은 수정하지 않음.

## 테스트 후 수정한 점
- 정상·오류 CSV로 테스트해 중복 ID·잘못된 참가 여부·미지의 메뉴·빈 신청번호·정원 초과가 모두 잡히는지 확인.
- 간식 메뉴를 하드코딩하지 않고, 안내문에 없는 값은 '예상치 못한 메뉴' 경고로 분리하도록 보완.
- BOM·빈 줄 처리 보완.
- 집계·변경 검증이 기대값과 모두 일치하여 수치 보정은 하지 않음.

## 결과
- 처음: 참가 10, 샌드위치 4, 주먹밥 4, 받지 않음 1, 미응답 1(A07), 생수 10.
- 변경(A06 불참→참가): 참가 11, 샌드위치 5, 주먹밥 4, 받지 않음 1, 미응답 1(A07), 생수 11.
- 증감: 참가 +1, 샌드위치 +1, 생수 +1, 그 외 유지. 기대값 일치.
- 산출물: `처음보고서.md`, `변경후보고서.md`, `참가신청_변경.csv`, `설명.md`.
