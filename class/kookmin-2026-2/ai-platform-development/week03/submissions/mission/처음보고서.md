# 사진동아리 가을 교류회 — 처음 행사 준비 보고서

> 참가 인원·간식 수량은 `scripts/count_attendance.py` 실행 결과(JSON)를 그대로 사용했습니다.
> 수치는 임의로 추측하거나 수정하지 않았습니다.

## 1. 행사 개요

| 항목 | 내용 |
| --- | --- |
| 행사명 | 사진동아리 가을 교류회 |
| 일시 | 2026년 9월 28일(월) 오후 6:30 ~ 8:00 |
| 장소 | 학생회관 소모임실 |
| 정원 | 12명 |
| 준비 담당 도착 | 오후 6:00까지 |

## 2. 참가 현황

집계 기준일: 참가신청.csv(9월 23일 오후 내려받은 현황)

| 구분 | 인원 |
| --- | --- |
| 전체 신청 기록 수 | 12건 |
| 참가 | 10명 |
| 불참 | 2명 |
| 참가 여부 불명확 | 0명 |

- 정원 12명 중 참가 10명 → **여유 2명, 정원 초과 아님**.

## 3. 간식 집계

간식은 참가자(10명)만 대상으로 집계했습니다. 불참자의 간식 선택은 제외했습니다.

| 항목 | 수량 | 비고 |
| --- | --- | --- |
| 샌드위치 | 4개 | 참가자 선택 |
| 주먹밥 | 4개 | 참가자 선택 |
| 받지 않음 | 1명 | 간식 주문 없음 |
| 미응답(빈칸) | 1명 | 신청번호 **A07** — 확인 필요 |
| 생수 | 10개 | 간식 선택과 무관, 참가 인원수만큼 |

- 확정 주문 간식: **샌드위치 4 + 주먹밥 4 = 8개** (미응답 1명 확인 전까지 미확정분 제외).
- 미응답 A07이 메뉴를 고르면 샌드위치 또는 주먹밥이 1개 늘 수 있습니다.

## 4. 행사 준비 사항

### 지금 준비 가능한 물품
- 참가 명단과 이름표 (참가 10명 기준)
- 샌드위치 4개, 주먹밥 4개
- 생수 10개
- 사진을 띄울 노트북, HDMI 연결 확인
- 테이블 배치, 행사 후 정리 담당 배정

### 추가 확인이 필요한 사항
- **A07(한수빈) 간식 미응답** → 9월 25일(금) 오후 5시까지 메뉴 확인 후 주문 수량 확정.
  - 안내문 기준: 임의로 메뉴를 정하지 않음. 불참자의 빈칸은 확인 불필요(이번 미응답은 참가자 건이므로 확인 대상).
- 간식 **주문 확정**과 **실제 주문 완료**는 구분. 이 보고서는 아직 주문·예약을 뜻하지 않음.

## 5. 적용한 집계 기준

1. 참가 여부가 '참가'인 사람만 참가 인원에 포함.
2. '불참'은 참가 인원·간식 수량에서 제외.
3. '받지 않음'은 간식을 신청하지 않은 것으로 처리.
4. 빈칸은 '미응답'으로 따로 집계(메뉴 임의 지정 금지).
5. 간식 수량은 명시적으로 선택한 참가자만 집계.
6. 생수는 간식 선택과 무관하게 참가 인원수만큼.
7. 중복 신청번호·필수 컬럼 누락·예상치 못한 값은 경고/오류로 보고(이번 데이터는 해당 없음).
8. 정원과 참가 인원을 비교해 초과 여부 확인.
9. 모든 수량은 Python 실행 결과 기준.
